## Future Features & Development Plans

As a second-year Data Science student, I'm using The Wigology as a way to apply what I'm learning about Python, data analysis and machine learning to a real business.

My goal is to build more than just an online hair store. I want to create a platform that combines the art and science of hair with technology to make choosing and buying wigs more personalised.

### 1. Wig Recommendation System
- Build a system that recommends wigs based on customer preferences.
- Ask customers questions about their lifestyle, preferred textures, lengths and hairstyles.
- Start with Python-based rules and gradually explore machine learning as I develop my skills.
- Help customers understand why certain hair options may suit their preferences.

### 2. AI Hair Assistant
- Explore adding an AI assistant that can answer questions about hair.
- Help customers understand different hair origins, textures and maintenance.
- Eventually explore using images to recommend hairstyles based on face shape.

### 3. Improving the Shopping Experience
- Add a shopping cart and secure checkout.
- Allow customers to save their favourite wigs.
- Introduce customer accounts and order tracking.
- Make the website easier to use on mobile devices.

### 4. Data Analysis and Business Insights
- Use Python to analyse sales and customer preferences.
- Build a dashboard to track sales, popular hair types and business performance.
- Explore how data can help with pricing and stock decisions.
- Practise data visualisation using real business data.

### 5. Machine Learning
- Learn how to train and evaluate machine learning models.
- Explore predicting which hair products customers may prefer.
- Investigate demand forecasting as more sales data becomes available.
- Improve recommendations over time using customer feedback, with their consent.

### 6. Testing and Deployment
- Learn how to test my code and identify bugs.
- Set up automated testing using GitHub Actions.
- Deploy the application using Render.
- Monitor the website to make sure it runs reliably.

### My Learning Goal

This project is also part of my journey in Data Science. I'm still learning, so I plan to build the application step by step, starting with the basics and introducing more advanced features as my knowledge improves.

I want to use The Wigology to gain practical experience in Python programming, data analysis, machine learning and software development while building something meaningful for my business.
