THE WIGOLOGY — SMOOTHER INTERACTIVE WIG VIEWER

Copy main.py to your existing hair_business_app folder alongside pricing_studio.py, replacing your old main.py.
Copy the six JPG files from images/ into your existing images/ folder. Keep all your other images and .streamlit/secrets.toml.

Run from the hair_business_app folder:
python3 -m streamlit run main.py

In Build Your Dream Wig select Indian Wavy or Filipino Straight, then drag the wig in a curved or horizontal motion. The viewer blends adjacent photographs and eases into the nearest view when released.

Important: Three photographs cannot create true intermediate 3D angles. This is a smoother photo-based prototype, not a true 3D model.
